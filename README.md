# 私语手札 · Private Journal

一个运行于 SillyTavern 的纯前端 UI 扩展。它借助当前已配置的模型，把当前聊天、角色卡、User Persona 与本次生成实际激活的世界书内容，整理成一本按聊天独立保存的私人日志。

## 当前功能

- 四种独立篇章：印象、相处日记、情书、恋爱日记，标签页只展示本栏已保存内容
- 全部内容固定从 User 的视角观察和书写 Char
- “印象”可选择整体印象、气质外貌、性格细节、心动之处或输入自定义观察需求；第一次记录明确显示为“初印象”，后续才显示“印象”，每次生成独立保存
- “情书”由 User 写给 Char；“相处日记”记录两人已经发生的日常
- “恋爱日记”默认锁定，可让模型依据当前故事判定关系，也可由 User 确认；仅伴侣关系解锁
- 每页保存正文、故事日期、心绪与记忆依据，不再生成诗句、歌词或歌曲推荐
- 五套可随时切换并自动记忆的实体手札主题：暮色蔷薇、洛可可花园、蓝染芒影、托斯卡纳纹理与玉兰燕影
- 五套可与任意封面自由搭配并自动记忆的桌面：珍珠奶油、暮林胡桃、浅木芦影、橄榄暖木与玉兰墨砚
- 五个笔记本均使用带透明通道的独立主体素材，不再把原图的米色摄影底和独立书签一起显示
- 每套主题分别校准姓名坐标，自动把当前 User 与 Char 的名字落在该封面真实留白处；封面题签使用清雅楷体字族并降低视觉重心，点击封面可翻开或合上手札
- 打开后的双页尺寸由当前笔记本真实长宽比计算，内页使用米色道林纸质感；四个栏目改为书本右缘可点击书签，中央丝带书签可以直接合上手札
- 封面页左上角的装帧材料盘分为“封面”和“桌面”两排，可独立选择、任意组合；封面围绕书脊自然翻开，栏目切换时用纸页翻动衔接
- 内页采用宋体/思源宋体为正文、中文无衬线体为界面标签，正文不低于 16px，并以舒适版心、段落间距和清晰的标题层级呈现
- 生成语气会同时参考 User Persona 和聊天里 User 的真实措辞习惯，包括句长、克制程度、情绪强度、幽默与称呼方式
- 生成接口可自主切换“跟随正文 API”或“副 API”；副 API 直接选择 SillyTavern 已保存的连接配置，仍会读取当前角色卡、User Persona、最近对话、已激活世界书与扩展记忆
- 可开启“按故事日自动整理”：普通同日续写只累计内容，不调用手札 API；正文以“次日、翌日、第二天”等明确跨日词开场，或明确故事日期发生变化时，才追加一次 API 请求并批量同步印象、相处日记、情书、关系状态和已解锁的恋爱日记
- 正文仍在生成时，手动请求会排队到正文结束，不抢占主生成状态
- 每个板块的已生成内容默认折叠，点击标题后展开正文
- 情书使用更高的情感浓度，强调具体的眷恋、心疼、渴望与脆弱；恋爱日记至少三分之二用于描写 User 的情感和关系变化
- 按“角色 / 群组 + 当前聊天”隔离保存
- LocalForage 本地持久化，支持 JSON 备份导出
- 桌面和移动端响应式手札界面；右下角 `❦` 入口可拖动并记忆位置，也可从 SillyTavern 的魔法棒菜单打开
- 对虚构经历、视角错位和 User 语气偏差做提示约束

## 安装

1. 将本目录发布为一个 Git 仓库。
2. 在 SillyTavern 打开“扩展 → 安装扩展”。
3. 粘贴 Git 仓库 URL 并安装。
4. 打开任意角色聊天，点击或拖动右下角酒红色 `❦` 按钮；也可以在魔法棒菜单中点击“私语手札”。

本地开发时，也可把整个目录放入 SillyTavern 的 `data/<user-handle>/extensions/`，或安装为所有用户后放到 `public/scripts/extensions/third-party/` 对应目录。

## 数据与隐私

- 日志只保存在浏览器侧的 SillyTavern LocalForage 中；卸载扩展前请先导出。
- 生成时，相关聊天与设定会发送给正文 API 或你为手札选择的副 API。副 API 的地址、模型和密钥仍由 SillyTavern 连接配置管理，本插件不会复制、导出或单独保存 API Key。
- 其他前端扩展理论上也能访问浏览器侧数据；高度敏感内容不应仅依赖前端扩展实现强隔离。

## 已知限制 / 下一阶段

- 当前暂未加入页面手工编辑、全文搜索和 Markdown/PDF 导出。
- `generateQuietPrompt` 会使用 SillyTavern 当前生成链路中的上下文与世界书规则；具体进入模型的条目仍受扫描深度、触发词、预算和用户配置影响。
- 副 API 模式需要 SillyTavern 1.15.0 或更新版本提供的 Connection Profile 请求服务；请先在“API 连接 → 连接配置”中新建或导入副 API，再到手札内页底部选择。副 API 请求会在本地重新组装角色卡、Persona、最近 28 条对话（按上下文预算由近到远装入）、当前激活世界书和扩展提示。
- “按故事日自动整理”依赖正文中的明确时间标记。没有跨日线索时只保存观察基线，不追加 API；检测到跨日后，一次响应批量处理全部栏目。正文自身的 API 调用不计入这一次手札调用。
- 为避免误扣次数，“后来、清晨、晚上”等单独时段词不会被视为跨日；若正文长期不写日期或“次日”等标记，可以手动点击“写下这一页”。
- 生成协议使用适合长正文的标签格式，正文中的引号与换行不会再破坏 JSON 并以代码形式显示；仍兼容读取旧版 JSON 响应。
- 旧版已保存的“伪 JSON 正文”会在打开手札时尝试本地修复；旧版诗句和歌曲字段会在迁移时清除，以上过程都不会消耗 API。
- 批量输出采用短篇幅并按固定顺序解析；若模型输出被截断，插件会明确提示缺少的栏目并保存已经完整解析的栏目，不会静默失败或额外重试。
- 如果模型不支持或没有遵守 JSON 格式，扩展会保留原始生成文本作为降级日记页，而不是丢弃结果。
- 关系判定坚持明确关系优先：暧昧、单恋、调情或角色卡中的未来倾向不会自动解锁恋爱日记；User 可以手动确认当前故事关系。
- 旧版“初印象”页面会自动迁移并保留到新版“印象”栏目。
- 群聊目前以整个群组为一本手札，后续可增加“指定执笔角色”。

## 兼容性

面向提供 `SillyTavern.getContext()`、`generateQuietPrompt()` 与 `SillyTavern.libs.localforage` 的当前 SillyTavern 版本；使用副 API 时最低要求为 1.15.0。建议使用最新稳定版。
